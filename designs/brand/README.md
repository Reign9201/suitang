# 随堂：标志、颜色、字体和组件

应用叫「随堂」，取「随堂听课」的意思。界面按一间教室来设计：左侧年级栏是一块黑板，右侧内容铺在作业本的纸面上。学科做成搁板上的书脊，看完的课用红笔打勾，当前年级和当前学科用粉笔黄标出。黑板绿和红笔红是整套界面里仅有的两种强色，其余都是纸、墨和浅绿。

颜色值、圆角、线宽这些样式数值三端相同；尺寸（年级格、书脊、封面宽度）按屏幕大小调整，下面分别列出。

## 标志

标是一个田字格里放一个播放三角：外框是粉笔白的实线方框，中间一横一竖两条虚线，播放三角是粉笔黄。

- 放在黑板上时直接用，线条用粉笔白 `#F4F0E3`，三角用粉笔黄 `#F4C24D`，不带底色，高度 36（网页和 iPad）或 22dp（Android 顶栏）。
- 放在纸面上时套进黑板绿的圆角方块，也就是 App 图标：底色是从 `#23674F` 到 `#174836` 的竖向渐变，圆角是边长的 23.5%，标占边长的 64.6% 居中。首次打开的页面用 72（网页，直接引用 `logo.svg`）、64（iPad）或 52dp（Android）。

三端的标都按 64×64 的画布画，改的时候以这个坐标系为准：

| 部分 | 数值（64 画布） |
| --- | --- |
| 外框 | 从 (4, 4) 起，边长 56，圆角 1.5，线宽 3，粉笔白 |
| 竖向虚线 | 从 (32, 8.5) 到 (32, 55.5)，线宽 1.4，圆头，虚线 2.5 / 2.3，粉笔白 55% 不透明 |
| 横向虚线 | 从 (8.5, 32) 到 (55.5, 32)，同上 |
| 播放三角 | (26.2, 21.2) → (26.2, 42.8) → (44.9, 32)，填充粉笔黄，再描 5 宽的圆角边把尖角描圆 |

源文件在 `designs/brand/`：`logo.svg` 是带圆角的完整标志（1024×1024，圆角 230），`icon.svg` 是满铺无圆角的版本（系统自己裁圆角时用），`icon-1024.png` 是它的位图。

| 用到的地方 | 文件 |
| --- | --- |
| 网页标签页图标 | `web/logo.svg`（和 `designs/brand/logo.svg` 内容相同） |
| 网页加到主屏幕 | `web/apple-touch-icon.png` |
| iPad 图标 | `ios/BiliStudy/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png` |
| Android 图标 | `android/app/src/main/res/drawable/ic_launcher_background.xml`（黑板绿渐变）、`ic_launcher_foreground.xml`（标，已换算到 108dp 画布）、`ic_launcher_monochrome.xml`（单色版），由 `mipmap-anydpi-v26/ic_launcher.xml` 组合 |

## 字体

标题用楷体，正文用系统无衬线字体。三端各用各的办法拿到楷体：

| | 楷体 | 正文 |
| --- | --- | --- |
| 网页 | 霞鹜文楷屏幕版（`lxgw-wenkai-screen-webfont@1.7.0`，从 CDN 加载），加载不到时退回 Kaiti SC / STKaiti / KaiTi | `-apple-system`、`PingFang SC` 等系统字体 |
| iPad | 向系统按需下载「楷体-简」（`STKaitiSC-Regular`，不行再试 `STKaiti`），下载不到时用系统衬线字体 | 系统字体 |
| Android | 系统不带楷体，直接用衬线字体（大多数机型是思源宋体），即 `FontFamily.Serif` | 系统字体 |

楷体的用法：品牌名 30（网页字距 .06em，iPad 字距 2；首次打开页 iPad 32 加字距 3、Android 28sp）、页面标题 30–34、书架右侧的年级名 46（Android 不显示这一项）、书脊上的学科名 23（竖排，字距 .14em，长名字降到 16；Android 逐字排列，18sp，三个字以上降到 13sp）、继续学习卡的标题 21、章节名 16（Android 15sp）、推荐批注 16（iPad 17）、已看完计数 25（Android 19sp）。小节的标题（推荐、整套课程、继续学习、收藏）用 23（Android 20sp）。Android 顶栏的标题是 21sp。

## 组件

组件的实现分别在 `web/app.css`、`ios/BiliStudy/UI/Theme.swift`、`android/.../ui/Theme.kt`，同名同参数。

### 田字格

选择年级的方块。外框实线，中间一横一竖两条虚线。

| | 黑板上的（年级栏） | 纸面上的（首次打开） |
| --- | --- | --- |
| 尺寸 | 网页和 iPad 46，Android 44dp | 网页 80，iPad 84，Android 66dp |
| 圆角 | 3 | 网页首次打开页 4，iPad 和 Android 3 |
| 框 | 1.5 宽；未选中是粉笔线，选中是粉笔黄 | 1.5 宽，田字格线 `#A9CBB9`；网页悬停时线变黑板绿 |
| 填充 | 未选中透明，选中粉笔黄 | 白色 |
| 字 | 楷体 24（「高一」这类两字的降到 17），未选中粉笔白，选中深黑板绿 | 楷体：网页 40（两字 27）、iPad 42（两字 30）、Android 28（两字 20），墨色 |
| 虚线 | 1 或 2 宽，虚线间隔 3 / 3 或 6 / 6 | 同左 |

### 书脊

一排书立在搁板上。当前学科的书脊比其余高一些、宽一些，顶上夹一条粉笔黄书签。

| | 网页 | iPad | Android |
| --- | --- | --- | --- |
| 宽（未选中／选中） | 58 / 66 | 58 / 66 | 44dp / 50dp |
| 高 | 152、144、158、140、150、146、156、142、150 轮流取，选中再加 26 | 同网页 | 124、118、130、114、122、118、128、116、122 轮流取，选中再加 24dp |
| 圆角 | 上 6、下 2 | 上 6、下 2 | 上 4、下 1 |
| 搁板 | 底部 10 宽的实心黑板绿条，两端圆角 4 | 同网页 | 底部 8dp 高的黑板绿条 |
| 书签 | 12 宽、30 高，在书脊右上角上方 12 处，底部从 80% 处开叉 | 同网页 | 10dp 宽、24dp 高，右上角外 7 宽 10 高 |

Android 的书脊高度整体比网页小一号，因为手机上的书架只有 172dp 高，按网页的高度放不下。排序和错落的规律保持一致。

### 卡片

白色底，圆角 18，一层很淡的阴影。网页是 `0 1px 2px rgba(28,43,38,.05)` 加 `0 6px 18px rgba(28,43,38,.07)`；iPad 是 `Theme.ink` 7% 不透明、半径 9、下移 4；Android 用 3dp 阴影，墨色 25% 作为环境色和点色。网页悬停时上移 2 并加深阴影。

### 标签

| 类型 | 底 | 字 | 说明 |
| --- | --- | --- | --- |
| 普通 | `#EDF2EF` | `#52605A` | 版本、难度、集数 |
| 类型 | `#E5F0EA` | `#1F5C47`，字重 500 | 同步课、专题讲解等 |
| 新教材 | `#FCEFC7` | `#6E5200` | 2024 年秋季后的新教材 |
| 描边 | 透明 | `#52605A`，1 宽 `#E2E8E4` 描边 | 搜索结果里这条课属于哪个年级学科 |

标签的字号 12，圆角 6，内边距 5×8（Android 是 4×8）。网页里「复习」标签另外用 `#FBEDE5` 底配 `#95471F` 字。

### 筛选胶囊

白色底，圆角 999（Android 是 24dp），1 宽 `#E2E8E4` 描边，最小高度 44（Android 48dp），左右内边距 14。选中时底变黑板绿、字变白，右侧的计数从三级墨变成淡粉笔白。

「上册 / 下册 / 全部」这组用的是另一种：外面一个白色胶囊套住，内边距 3，里面每项最小高 38、左右 18，选中的项填黑板绿。

### 按钮

两种。主按钮是黑板绿底白字，次按钮是白底 1.5 宽 `#E2E8E4` 框，圆角都是 12，最小高度 44（Android 48dp），左右内边距 18–20，字 14 到 15、字重 500。不可用时整体降到 35% 不透明。

### 书签按钮

收藏用的图标按钮。点击区域 44×44（Android 48dp），图标 19（Android 用默认的 24dp 图标）；放在封面右上角时垫一个 38 的白色圆（92%–94% 不透明）加一点阴影。未收藏是三级墨的空心书签，收藏后变红笔色并填充。

### 封面

视频封面一律 16:9。网页和 iPad 的列表行、继续学习卡里封面宽 176，Android 的列表行 112dp、继续学习卡和收藏 104dp；推荐卡片里的封面铺满卡片宽度，圆角由卡片给出，封面自己不带圆角。封面圆角：列表和继续学习卡 12（Android 10dp），推荐卡片 0。封面右下角的时长是白字（网页 11.5，iPad 12，Android 11sp）配 `rgba(14,26,22,.74)` 底、圆角 6（Android 4dp），距边 7（Android 5dp）。

### 进度条

高 6，两端圆头，底是浅绿 `#E5F0EA`，填充是黑板绿。放在封面底部时高度降到 4，底改成 `rgba(0,0,0,.3)`，填充改成粉笔黄。填充宽度最小不低于高度，进度接近 0 时也留一个圆点。

## 术语说明

**田字格**：小学生练写字用的方格，外面一个实线方框，中间一横一竖两条虚线把它分成四小格。界面上用它表示年级。

**书脊**：书立在书架上时朝向外面那一面，通常印着书名。界面上用它表示学科，一排书脊立在一条黑板绿的搁板上。

**pt（点）与 dp（密度无关像素）**：iPad 和 Android 上表示界面尺寸的单位，都会随屏幕密度自动换算成实际像素，写代码时按逻辑尺寸写。本文档里写的 46、200 这类数字，网页是像素，iPad 是 pt，Android 是 dp。

**CSS 变量**：网页样式表里用 `--名字: 值` 定义、用 `var(--名字)` 引用的值，改一处全文生效，这里用来放颜色。

**霞鹜文楷**：一款开源的中文楷体字体，正式名称 LXGW WenKai。网页版从 CDN 加载它的屏幕显示版本。

**楷体-简**：苹果提供的一款中文楷体字体，正式名称 `STKaitiSC-Regular`。iPadOS 默认不预装，应用第一次用到时向系统申请下载。

**CDN**：内容分发网络，把静态文件放在离用户近的服务器上，网页加载字体这类资源时常用。

**自适应图标**：Android 8.0 起的图标格式，把图标拆成背景、前景、单色三层，由系统按各家厂商的形状（圆形、方形、圆角方形）自己组合裁切。对应 `mipmap-anydpi-v26/ic_launcher.xml`。

**AppIcon**：iOS 的图标资源，放在 `Assets.xcassets` 的 `AppIcon.appiconset` 里，一个 1024×1024 的 PNG 就够了，其余尺寸由 Xcode 生成。

**SwiftUI / Jetpack Compose**：SwiftUI 是苹果的界面开发框架，iPad 版用它写；Jetpack Compose 是 Android 的界面开发框架，Android 版用它写。

**claude-design 画布**：本项目 `designs/` 下那种可以并排摆多张页面、缩放拖拽查看的设计稿文件格式，扩展名是 `.dc.html`。
